# ⚡ Saffan — Self-Taught Software Engineer & Systems Architect

> **Portfolio & Production Systems Showcase** | Built with Next.js 14 App Router, TypeScript, and Tailwind CSS.

---

## 🌟 Overview

This is the official portfolio and engineering showcase of **Saffan**, a self-taught software engineer specializing in:
- **Distributed Systems & Concurrency**: Go, Rust, gRPC, Redis Streams, Raft consensus.
- **AI Infrastructure & Vector Search**: FastAPI, Qdrant, LangChain, semantic caching.
- **High-Performance Web Platforms**: Next.js 14/15, TypeScript, WebGL, Web Workers, zero-bloat state management.

---

## 🚀 Key Features

- 🖥️ **Interactive Hero Terminal**: Fully interactive Bash emulator with live runnable commands (`whoami`, `skills`, `projects`, `journey`, `sudo hire-saffan`).
- ⚡ **Flagship Production Systems**: Deep-dive architecture reviews, latency benchmarks, and live metrics for 4 major systems.
- 🧬 **The Self-Taught Trajectory**: Chronological timeline of self-directed mastery from low-level C and kernel concepts to distributed scale.
- 📊 **Filterable Tech Stack Matrix**: Categorized across Languages, Backend, Databases, Frontend, and DevOps with practical application notes.
- ⌘ **Global Command Palette (`⌘K`)**: Seamless keyboard-driven navigation.
- 📱 **100/100 Core Web Vitals**: Zero layout shift, instant rendering, and responsive dark midnight design.
